# 第一轮最小可验证实验

## 实验

`HY-EXP-0001`：5 分钟成交压力过冲回撤。

完整冻结参数位于：

```text
registry/experiments/HY-EXP-0001/preregistration.json
```

## 最小性

- 只测试 H1；
- 只有一组信号参数；
- 只有一个固定持有期；
- 不做网格搜索、不挑最佳币种、不调整成本；
- 只回答“该固定机制在已暴露开发数据上是否值得扩大验证”。

## 成功和失败

实验工具链成功是指：

- 所有原始文件有 URL 和 SHA-256；
- 信号只使用收盘数据；
- 交易只在下一根 5 分钟开盘成交；
- 资金费和三档成本可逐笔复算；
- 逐笔、分币种、分方向、分半年结果落盘；
- 通过或失败都写入登记链。

策略规格的开发筛选通过不等于策略晋级。它仍然缺少无幸存者偏差全市场复测、盘口冲击、独立前向和 180 日/100 笔门槛。

## 已完成结果

`HY-EXP-0001` 产生 416 笔交易并被淘汰。压力情景 PF 为 0.607，净收益单位为 -1.0819；删除最佳 5 笔后仍为 -1.2688；只有 1/8 币种和 1/5 半年区间盈利，多空方向都为负。

完整结果：

```text
artifacts/HY-EXP-0001/report.md
artifacts/HY-EXP-0001/result.json
artifacts/HY-EXP-0001/trades.csv
artifacts/HY-EXP-0001/data-manifest.json
```

该固定规格不得继续调参包装。后续若研究不同的短周期成交压力机制，必须登记新的假设差异和实验 ID。
