# 第七轮最小实验：HY-EXP-0011

## 假设

经济属性相近但并非同一标的的永续合约，可能围绕滚动事前Beta形成可重复的相对价值回归。固定配对为BTC/LTC、ETH/ETC、SOL/AVAX、ADA/DOT；它们不因历史收益调整，也不继承旧项目趋势突破规则。

本实验不同于H4。H4交易同一基础资产的USDT/USDC报价残差，理论上存在同标的锚；H7承担真实的跨资产基差风险，只验证相对价格回归能否在成本和资金费之后仍有正期望。

## 冻结规则

- 从完整5分钟K线严格聚合UTC对齐的4小时K线；
- 每次只用此前90天、540根完整4小时K线估计收益Beta；
- 用同一事前窗口的价差水平均值和样本标准差计算当前z-score；
- `|z| >= 3`入场，回到`|z| <= 1`后才允许再次武装；
- 信号4小时K线结束后等待一根完整5分钟处理K线，再在下一根5分钟开盘成交；
- 以入场时冻结的Beta和中心判断收敛，最迟持有7天；
- 每个配对最多占账户总毛敞口25%，四组同时出现也不超过一倍毛敞口；
- 每条腿计手续费、滑点和实际资金费，并检验额外5分钟延迟；
- 参考1万美元账户，每腿不得超过信号前12根5分钟K线最低成交额的2%。

## 淘汰条件

压力情景至少40笔配对交易、PF不低于1.30、净收益为正、删除最佳5笔及最佳5个入场日后仍盈利、最大回撤不低于-20%、至少3/4配对盈利、残差高低两个方向盈利、至少3个半年盈利。单一月份及单一配对都不能贡献超过全部正贡献的40%，极端成本和延迟5分钟也必须盈利。

任何一项失败即淘汰精确规格。结果只属于D0开发筛选；查看结果后不得替换配对、修改90天窗口、降低3σ门槛或缩短持有期。

## 固定结果

720/720份币安官方月度档案可用。四组固定配对共执行18笔交易，仅ETH/ETC有1个信号因容量不足跳过。

压力情景净收益单位+0.029581、PF 1.370、最大回撤-0.054904；极端成本净收益+0.022462，延迟5分钟净收益+0.024337。四组中BTC/LTC、SOL/AVAX、ADA/DOT盈利，ETH/ETC亏损；残差高低两个方向均盈利。

但只有1/18交易穿越冻结中心，其余17笔都在7天上限退出。最佳5笔贡献全部压力净收益的293.2%，删除后为-0.057163；交易数不足40，正收益月份最大贡献40.66%也超过40%上限。失败项为交易数、删除最佳5笔、删除最佳5入场日和月份集中度，结论固定为 `EXACT_SPECIFICATION_ELIMINATED`。
