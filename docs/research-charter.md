# 衡域研究章程

## 1. 项目身份

项目中文名为“衡域研究”，英文名为 “Hengyu Research”，代码仓库名为 `hengyu-research`。

本项目是全新的币安永续合约研究项目，不是“恒势永续”的 V16 或任何延续版本。旧项目截至 V15 的研究结论统一记为“未证明有效”。旧项目的历史盈利结果、候选参数和前向失败记录只可作为对照和风险警示，不能作为新项目的先验通过证据。

## 2. 研究目标

在真实手续费、双向滑点、资金费率、信号到成交延迟、最小下单量、流动性冲击和退市风险下，寻找可重复、可执行的正期望币安永续合约策略。允许做多、做空、横截面配对、市场中性和预先冻结的状态切换。

盈利是最终目标，但任何盈利结论必须服从证据纪律。缺少独立前向数据时，正确结论只能是“待验证”或“未通过”，不能用更多参数搜索替代证据。

## 3. 当前非目标

- 不编写或接入生产下单接口。
- 不部署 Vercel、Supabase、邮件或网页服务。
- 不迁移旧策略规则。
- 不用截至 2026-07-30 的数据宣称独立样本外盈利。
- 不为提高信号频率而降低期望值门槛。

## 4. 证据等级

| 等级 | 含义 | 允许的结论 |
|---|---|---|
| D0 开发数据 | 市场事件时间早于前向边界，或规则在查看结果后发生过修改 | 提出、筛选、排除假设 |
| D1 开发内走步 | D0 内严格因果的滚动训练/验证 | 检查流程和稳健性，不是独立样本外 |
| F0 前向影子 | 冻结规则后实时产生、未用于调参的数据 | 累积候选证据 |
| F1 最低观察完成 | 同时达到 180 日和 100 笔已关闭交易 | 可以进行晋级审查，不能自动通过 |
| L0 真钱交易 | 另行书面批准并完成安全审查 | 当前禁止 |

用户原文“至少 180 天或 100 笔”存在“任一满足”与“两个都满足”的语言歧义。本章程采用更保守的“两个都满足”；降低该门槛必须作为独立治理变更登记，不能由实验结果触发。

## 5. 晋级标准

候选策略只有在 F1 阶段同时满足以下条件时，才可被称为“具备进入实盘审批的证据”，而不是“保证盈利”：

- 前向净收益为正；
- 前向 PF 不低于 1.30；
- 最大回撤不超过 20%；
- 删除最佳 5 笔后仍盈利；
- 提高手续费和滑点后的压力情景仍盈利；
- 不依赖单一币种、单一月份或单一方向；
- 回测与影子成交偏差在预注册容差内；
- 参数在整个前向期保持冻结。

任何一项失败都不得通过修改同一候选的参数来延续其前向计时。修改规则会创建新的实验和新的前向起点。

## 6. 安全边界

- `authorization` 必须为 `PAPER_ONLY`。
- `liveOrdersEnabled` 必须为 `false`。
- 当前仓库不得出现币安私有交易端点、API Key 或 Secret。
- 所有数据库对象必须使用 `hengyu_` 前缀，不得读写 `hengshi_` 表。
- 生产部署、真钱下单和权限扩展需要用户再次明确批准。

## 7. 研究职责

每个实验必须有预注册、数据清单、代码提交、结果工件和结论事件。失败、无信号、数据缺失、执行错误和被淘汰的参数都必须保存。研究者不能删除失败来改变总体命中率。
