# 第六轮最小实验：HY-EXP-0010

## 盈利假设

部分永续合约的资金费率具有跨结算周期的持续性。每14天做多近期累计资金费率最低的合约、做空最高的合约，并用BTC去除事前市场Beta，可能获得可覆盖换手成本的实际资金费率现金流。

这不是H2的结算后价格回归，也不使用H2的阈值或持有期。H2在结算后入场且明确不赚取该次资金费；本实验以跨多个未来结算周期实际收到的资金费为核心收益机制。

## 冻结时序

- 固定16币诊断面板，BTC不参与横截面排名，只作为Beta对冲腿；
- 从2024-01-01 00:00 UTC开始每14天形成一个独立组合事件；
- 资金费率得分只累计 `(事件时点-14天, 事件时点]` 已结算费率；
- 等待事件时点后的第一根完整5分钟K线，再于事件后10分钟的5分钟开盘成交；
- 选取过去30天成交额最高的12个山寨币，在其中做多得分最低3个、做空最高3个；
- 山寨币两侧分别按事前残差波动率倒数加权，再增加BTC Beta对冲并统一总敞口；
- 预测资金费收入必须至少24 bp，等于压力情景冻结的往返手续费与滑点成本；
- 持有14天，下一组合与上一组合在各自成交情景中首尾相接；
- 基准、压力、极端、延迟5分钟四种情景同时保存。

## 淘汰原则

压力情景必须同时达到PF不低于1.30、净收益为正、去掉最佳5期仍盈利、回撤不低于-20%、至少8个山寨币盈利、多空两侧盈利、BTC事前上涨和下跌状态均盈利、至少3个半年盈利且月份不过度集中。实际资金费收入扣除手续费与滑点后也必须为正；极端成本及延迟5分钟仍须盈利。

任一失败即淘汰精确规格。所有数据属于D0开发数据，即使通过也不能宣布具备实盘价值，且不得在同一数据上调整14天周期、24 bp门槛或排名数量来包装结果。

## 固定结果

官方月度档案1920/1920份可用，固定日程产生62个候选组合；46个未达到24 bp预测携带门槛，3个未通过容量约束，最终只有13个组合入场。

压力情景净收益单位为+0.125100、PF 1.981、最大回撤-0.087184；极端成本和延迟5分钟仍为正，实际资金费扣压力执行成本后为+0.004698。但最佳5期合计收益超过全部净收益，删除最佳5期后为-0.060001；低费率多头侧为-0.023641，且ETH单币贡献全部压力净收益的100.3%，删除ETH后为-0.000381。

预登记失败项为最少事件数、删除最佳5期后盈利、多空两侧盈利。精确规格结论固定为 `EXACT_SPECIFICATION_ELIMINATED`。不得在相同D0数据上降低24 bp门槛、缩短周期、删除ETH、只保留空头侧或改变排名数量来包装下一版本。
