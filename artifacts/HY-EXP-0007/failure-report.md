# HY-EXP-0007 失败报告

结论：`DATA_VALIDATION_FAILED_BEFORE_PNL`。

数据清单锁定后、任何价差或 PnL 计算前，严格解析发现16条 USDT/USDC 两腿 mark-price 月归档均缺少 `2026-06-29T00:00:00Z` 至 `2026-06-30T00:00:00Z` 的完整一天，共每个合约288根5分钟记录。每个受影响的2026-06归档只有8352行；同期 BTCUSDT 合约K线有完整8640行。

预登记质量规则要求 mark-price 序列连续，因此不能删除该日、插值或仅在实际命中资金费事件时忽略缺口。实验在收益计算前失败，没有产生任何交易或绩效指标。

下一实验只能使用新 ID，并在查看任何 H4 收益前冻结替代的资金费结算 mark 来源。经济信号、阈值、流动性和退出规则不得借此修改。
